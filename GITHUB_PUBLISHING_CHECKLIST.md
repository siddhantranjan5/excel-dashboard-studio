# GitHub Publishing Checklist

## Suggested repository metadata

- **Repository name:** `excel-dashboard-studio`
- **Description:** Browser-based Excel/CSV analytics dashboard with data cleaning, worksheet relationship suggestions, KPI cards, interactive charts, and Power BI DAX helpers.
- **Suggested topics:** `excel`, `dashboard`, `business-analytics`, `data-visualization`, `chartjs`, `javascript`, `power-bi`, `data-cleaning`, `github-pages`
- **Website:** Add the GitHub Pages URL after deployment.
- **Visibility:** Public only if you have rights to publish all code and dependencies.

## Before publishing

- [ ] Confirm you own or are allowed to publish the HTML and all included code.
- [ ] Review the license and update the copyright holder if needed.
- [ ] Test the app in a modern desktop browser and on a narrow/mobile viewport.
- [ ] Check that no real data, API keys, passwords, or personal information are included.
- [ ] Confirm the external library dependencies and versions are acceptable.
- [ ] Add screenshots or a short GIF of the app using your own sample data (optional, but recommended).
- [ ] Create the repository and upload all files from this folder.
- [ ] Enable GitHub Pages using the default branch and repository root.
- [ ] Test the published site URL.

## Suggested first commit

`Initial release: Excel to Dashboard Studio`

## Suggested short social / portfolio description

Excel to Dashboard Studio is a client-side analytics tool that turns Excel workbooks and CSV files into interactive dashboards. It combines data profiling and cleaning, heuristic worksheet relationship detection, calculated columns and measures, KPI cards, interactive charts, and DAX formula suggestions in a simple static web app.
